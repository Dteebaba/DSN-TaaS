# Changelog

## v0.3.0 (2026-09-29)
- Repository split into `frontend/` and `backend/` with tests, CI and deployment config.
- One-click test access for Admin, Partner (subscribed and free), Talent and Reviewer.
- Supabase backend: database schema, access rules, sample data and tests.
- Screen catalogue PDF in `docs/`.

## v0.2.0 (2026-09-29)
- Members can request verification for several roles at once.
- Reviewers set the final role and level for each request, edit other roles and add roles, using the role manual.
- Verified roles and claimed roles look clearly different everywhere.
- Admin can edit the role manual.

## v0.1.0 (2026-09-28)
- First working prototype: applications, DSN ID login, CV builder, DSN Rating (5 × 20), role verification, recruiter subscriptions, admin and impact tracking.
- Welcome page with motion and the official DSN colours.
